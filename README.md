# Spacetime Engine

**Spacetime Engine** is an original and extensible BedWars engine created in reverence to `spacetime1000`, an extraordinary PvP player and the inspiration behind this project.

## Project status

The project is currently in its initial development stage.

Current foundation:

- Java 21
- Gradle 9.6.1
- Gradle Wrapper
- Paper API
- Original source code
- Basic plugin lifecycle
- Reproducible builds

## Building

Clone the repository and run:

```bash
./gradlew clean build
```

The compiled plugin will be generated at:

```text
build/libs/spacetime-engine-0.1.0-SNAPSHOT.jar
```

## Vision

Spacetime Engine aims to provide a modular and extensible foundation for BedWars servers, including:

- Arenas
- Teams
- Beds and final eliminations
- Respawning
- Resource generators
- Item shops
- Team upgrades
- Spectator mode
- Statistics
- Match queues
- Multiple game modes
- Network integration

## Development

Spacetime Engine is being developed from scratch as an independent learning and engineering project.
